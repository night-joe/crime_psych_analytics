# Chapter 6: SQL Aggregations & Joins

## 📌 Key Topics & Subtopics
- [ ] **Aggregate Functions**
  - COUNT(), SUM(), AVG(), MIN(), MAX()
  - Grouping results with GROUP BY
  - Filtering aggregates with HAVING vs WHERE
- [ ] **Table Joins**
  - INNER JOIN: Matching records in both tables
  - LEFT JOIN: All records from left + matches from right
  - RIGHT JOIN: All records from right + matches from left
  - FULL OUTER JOIN: All records when there is a match in either
  - CROSS JOIN & Self Joins
