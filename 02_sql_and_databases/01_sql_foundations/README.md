# Chapter 5: Relational Databases & SQL Foundations

## 📌 Key Topics & Subtopics
- [ ] **Relational Database Concepts**
  - Tables, columns, rows, primary keys, foreign keys, schemas
- [ ] **Basic Querying (SELECT)**
  - SELECT column1, column2 FROM table
  - Alias column names (AS new_name)
  - Distinct values (SELECT DISTINCT ...)
- [ ] **Filtering Data (WHERE)**
  - Operators: =, !=, >, <, >=, <=
  - Logic: AND, OR, NOT
  - Special filters: IN (...), BETWEEN x AND y, LIKE '%pattern%', IS NULL / IS NOT NULL
- [ ] **Sorting & Page Limits**
  - ORDER BY column ASC/DESC
  - LIMIT n / OFFSET m
