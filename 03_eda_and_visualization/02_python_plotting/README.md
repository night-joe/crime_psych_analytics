# Chapter 10: Python Plotting Libraries

## 📌 Key Topics & Subtopics
- [ ] **Matplotlib Core**
  - Figures and Subplots (plt.subplots(nrows, ncols))
  - Customizing titles, labels, ticks, gridlines, legends
  - Saving high-res figures (plt.savefig())
- [ ] **Seaborn Statistical Plots**
  - Categorical plots: sns.barplot(), sns.boxplot(), sns.violinplot()
  - Distribution plots: sns.histplot(), sns.kdeplot()
  - Matrix plots: sns.heatmap(df.corr(), annot=True)
  - Pair plots: sns.pairplot()
- [ ] **Interactive Visualizations with Plotly**
  - plotly.express: px.scatter(), px.line(), px.bar()
  - Interactive tooltips, zooming, and filtering in Jupyter
