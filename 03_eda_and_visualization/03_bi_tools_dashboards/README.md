# Chapter 11: Business Intelligence & Dashboarding

## 📌 Key Topics & Subtopics
- [ ] **BI Tool Choice: Power BI / Tableau**
  - Ingesting data & building data models (Star schema, Snowflake schema)
  - Relationships (1:Many, Many:1)
- [ ] **Calculations & Measures**
  - Power BI DAX: SUM, CALCULATE, ALL, FILTER, Time Intelligence (SAMEPERIODLASTYEAR)

- [ ] **Interactive Dashboard Construction**
  - Creating interactive slicers, cross-filtering, drill-through pages
  - Layout design, navigation buttons, KPI summary cards
